## 📖 系统简介

**启灵同城综合服务与全品类回收系统**是一套专为中国本土商业生态量身打造的**全链路数字化综合运营平台**。系统底层采用**轻量原生 PHP 高性能架构**，零臃肿复杂第三方框架依赖，极速响应，秒级启动，具备极强的稳定性、可维护性与私有化二次开发能力。

系统独创**双核业务驱动引擎**，深度融合了**「同城上门生活服务」**与**「全品类闲置物资回收」**两大万亿级赛道：
* 既可作为纯**同城到家生活服务平台**（家政保洁、家电拆洗高温消杀、社区快修、管道疏通、上门伴宠等）独立运营；
* 亦可作为纯**全品类闲置回收变现平台**（数码3C、废品再生资源、二手车与机动车报废、奢侈品黄金名表、大家电拆旧等）独立运营；
* 更可开启**双核旗舰模式**，首页与小程序端无缝切换互导流量，打造高黏性、多频次触达的本地数字化生活便民门户！

## 🚀 极简部署指南（宝塔面板 / 本地 LNMP）

### 1. 基础服务器环境要求
* **操作系统**：Linux (CentOS 7.9+ / Ubuntu 20.04+ / Debian 11+ / Alibaba Cloud Linux / Windows Server)
* **Web 服务器**：Nginx 1.18+ (推荐 1.22 ~ 1.26)
* **PHP 版本**：PHP 7.4 / 8.0 / 8.1 / 8.2（推荐 **PHP 8.0 或 8.1**）
* **必需 PHP 扩展**：`pdo`、`pdo_mysql`、`curl`、`mbstring`、`openssl`、`gd`、`fileinfo`（宝塔后台一键勾选安装）
* **数据库**：MySQL 5.7+ 或 MySQL 8.0（数据库字符集：`utf8mb4`）
* **缓存服务**：Redis 5.0+（可选推荐；若未安装，系统将全自动无感降级为内置本地文件高速缓存）

---

### 2. 后端服务端极简部署步骤

1. **创建站点与上传代码**：
   - 在宝塔面板新建网站，将本仓库 `backend` 目录中的全部文件上传到网站根目录；
2. **【关键】配置站点运行目录**：
   - 进入站点设置 ➔【网站目录】，将**运行目录**修改选择为 `/public`，点击保存；
3. **配置目录读写权限**：
   - 确保 Web 用户（如 `www`）对以下目录具备读写权限（`chmod -R 775`）：
     - `backend/runtime/`
     - `backend/config/`
     - `backend/public/uploads/`
4. **配置 Nginx 伪静态与安全防护规则**：
   - 进入站点设置 ➔【伪静态】（或 Nginx 配置文件中），加入以下核心规则：
   ```nginx
   # 1. 核心单入口伪静态重写
   location / {
       try_files $uri $uri/ /index.php?$query_string;
   }

   # 2. 顺丰开放平台直达回调推送 (免重写拦截，请根据 PHP 版本匹配 fastcgi)
   location ~* ^/(sf_push|sf_route|sf_state)\.php$ {
       try_files $uri =404;
       fastcgi_pass unix:/tmp/php-cgi-80.sock;
       fastcgi_index index.php;
       fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
       include fastcgi_params;
   }

   # 3. 上传目录安全屏障：禁止直接解析与执行 PHP 脚本，防范木马上传
   location ~* ^/uploads/.*\.php$ {
       deny all;
   }

   # 4. 敏感配置文件与日志防偷窥
   location ~* \.(env|git|sql|bak|log|lock|ini)$ {
       deny all;
   }
   ```
5. **浏览器图形化一键安装**：
   - 打开浏览器访问您的站点：`http(s)://您的域名/`；
   - 系统将自动引导进入可视化安装向导，自动检测系统扩展环境并引导输入数据库账号密码；
   - 点击【开始一键初始化安装】，系统自动完成数据建表与默认模板填充；
   - 安装完成后，即可直接进入 PC 官网前台，或登录管理后台（`https://您的域名/admin/`）开展业务！

---

### 3. 微信小程序端快速编译与运行

1. 下载并安装官方 **[HBuilderX](https://www.dcloud.io/hbuilderx.html)** 编辑器；
2. 在 HBuilderX 中点击【文件】➔【导入】➔【从本地目录导入】，选择本仓库中的 `miniapp` 目录；
3. 打开 `miniapp/common/config.js`，修改配置您的后端服务端接口域名地址：
   ```javascript
   export default {
       baseUrl: 'https://您的接口域名.com',
       brandName: '启灵同城服务',
       version: '2.0.0'
   };
   ```
4. 打开 `manifest.json`，在【微信小程序配置】中填写您的**微信小程序 AppID**；
5. 点击 HBuilderX 顶部菜单栏：【运行】➔【运行到小程序模拟器】➔【微信开发者工具】；
6. 微信开发者工具自动启动预览，确认无误后点击【发行】➔【小程序-微信】即可一键上传发布审核！

## 🔒 生产环境安全与运维建议

* **自定义管理后台路径**：为防范外部恶意机器人对默认 `/admin/` 路径进行暴力探测，管理员可直接进入服务器将 `backend/public/admin/` 文件夹重命名为您想要的私密名称（例如 `public/qiling_manage_888/`），无需修改任何服务端代码，即可通过 `https://您的域名/qiling_manage_888/` 访问后台！
* **全站 HTTPS 加密**：生产环境强烈推荐配置免费的 Let's Encrypt 或商业 SSL 证书，并开启强制 HTTPS，保障支付与用户信息加密传输；
* **关闭调试输出**：生产部署上线后，请确认 `backend/config/app.php` 中的 `debug` 设置为 `false`，以防系统敏感报错外泄。
