## 📖 项目简介

**启灵二手回收系统**是一套专为中国本土商业回收生态量身定制的全流程解决方案。系统采用**“轻量原生 PHP 后端 + Uni-app 跨端移动客户端”**架构，零臃肿复杂第三方包依赖，极速响应，易于二次开发与私有化部署。

系统内置行业领先的**多模态回收估价引擎**，支持从数码 3C 精品估价到大宗废品称重、二手车残值报废评估等 6 大行业业务场景的一键平滑切换。

### 🌟 核心特性
* **🚀 极简部署体验**：自带图形化一键安装向导，自动检测环境、自动建表建库，小白站长也能 5 分钟极速上线；
* **🔄 6 大主流行业模板一键切换**：
  1. **综合全品类大平台模式**：全品类网格化自由展示；
  2. **废品与再生资源模式**：废铜废铝废纸电瓶，按**公斤/吨**称重计价，支持预约上门过磅；
  3. **二手汽车与机动车报废模式**：家用燃油车、新能源电动车报废残值申领，按**万元/辆**评估；
  4. **数码 3C 精品回收模式**：手机、电脑、平板、相机，精准成色多维减扣算法；
  5. **奢侈品名表黄金回收模式**：名表名包、足金999首饰，按件/克鉴定现金结算；
  6. **二手大家电拆旧模式**：空调、冰箱、洗衣机拆旧，上门拆机搬运；
* **🚚 顺丰速运全流程物流闭环**：官方开放平台 API 深度对接，支持预约上门取件、生成顺丰电子面单、实时路由轨迹跟踪、运费清单与订单状态 Webhook 自动推送；
* **🔍 质检中心与二次核价**：开箱验机存证、成色多维复核、生成专业质检比对报告，支持补差确认或原路退回；
* **💰 多渠道财务结算放款**：支持**微信商家转账到零钱**、**支付宝单笔转账**与线下银行卡结算，财务审核一键放款；
* **🛡️ 同服 Redis 多租户安全隔离**：默认绑定 `DB 2` 与专属 `sys_recycle:*` 业务前缀，底层严禁 `flushdb`，采用 `SCAN + UNLINK` 精准扫描注销，保障同服务器其他站点缓存 100% 零误伤。

## 🚀 快速上手

### 1. 后端部署（只需 4 步）
1. **添加站点**：在宝塔面板或 LNMP 中创建网站，将 `backend` 源码上传并解压；
2. **设置运行目录**：将网站运行目录（Web Root）设置为 `/public`（即 `.../backend/public`）；
3. **配置 Nginx 伪静态**：
   ```nginx
   location / {
       try_files $uri $uri/ /index.php?$query_string;
   }
   ```
4. **一键安装**：浏览器访问 `https://您的域名/`，按照图形化安装向导检测环境并完成数据库初始化。

> 📖 **完整详尽的 Nginx 生产配置、目录权限、顺丰直达规则及运维排错指南，请查阅 [DEPLOYMENT.md](DEPLOYMENT.md)**。

### 2. 小程序端编译与发布
1. 使用 **HBuilderX** 导入 `miniapp` 项目；
2. 打开 `miniapp/common/config.js`，将 `baseUrl` 改为您线上服务器的 HTTPS 域名；
3. 打开 `miniapp/manifest.json`，在【微信小程序配置】中填入您的小程序 `AppID`；
4. 点击【运行】➔【运行到小程序模拟器】➔【微信开发者工具】进行联调预览与上传发布。
