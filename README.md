# 启灵同城服务与全品类回收系统

本项目是一套包含 PC 网页端、微信小程序端和后台管理系统的同城生活服务与闲置物品回收系统。

---

## 系统简介

本系统主要用于搭建同城本地生活服务与物品回收平台，包含以下核心部分：

- **PC 网页端**：用户前台官网，支持服务项目浏览、在线预约下单、回收估价、公告查看等。
- **微信小程序端**（基于 uni-app 开发）：移动端用户入口，与网页端数据互通。
- **师傅作业端**：师傅移动端页面，支持师傅接单、查看工单详情、上传作业照片与完工核销。
- **管理后台**：管理员工作台，负责订单管理、服务与分类配置、行业模板切换、资金结算、内容发布等。

### 支持的业务场景

1. **同城上门服务**：
   - 适用于家政保洁、家电清洗、水暖电路维修、管道疏通、开锁换锁、上门喂宠遛狗等上门到家业务。
   - 支持按项目、按面积、按时长或定金等多种方式计价。
   - 支持在后台为不同行业添加自定义预约字段（如房屋面积、宠物种类、故障描述等）。

2. **闲置与废品回收**：
   - 适用于二手手机数码、废旧金属物资、报废车与二手车、黄金名表奢侈品、旧家电等回收业务。
   - 支持多步骤成色评估问答与在线估价。
   - 支持顺丰快递寄件回收或师傅上门回收。

3. **双业务混合或单业务运营**：
   - 可以在后台自由开启或关闭「上门服务」与「闲置回收」模块。既可以只做生活服务，也可以只做闲置回收，或者两项业务同时运营。
   - 后台提供多种行业预设模板（如通用综合、家政保洁、家庭维修、宠物服务、数码回收、废品回收、汽车回收、奢侈品回收等），切换后会自动适配对应的主题色、角色称呼和表单项。

## 主要功能

- **服务预约与表单**：用户选择服务规格与预约时间，填写联系信息及行业专属字段后提交订单。
- **回收在线估价**：根据商品的品牌型号与机况选项，自动计算预估回收金额。
- **师傅接单与核销**：后台可将订单指派给师傅，师傅也可自主抢单，上门完成后上传凭证并核销订单。
- **支付与结算**：
  - **用户向平台付款**：支持官方微信支付与支付宝支付，用于购买到家服务。
  - **平台向用户打款**：支持微信商家转账到零钱、支付宝转账及线下银行打款，用于支付回收款项。
- **公告系统**：后台可发布图文公告，PC 网页端首页支持横幅平滑滚动播报，小程序端首页支持原生轮播展示。
- **物流对接**：支持对接顺丰开放平台 API，支持在线预约取件、生成面单与物流轨迹跟踪。
- **优惠券与补贴**：支持满减券、加价券等，新用户注册可自动发券，下单时自动推荐抵扣。
- **新订单提醒**：后台支持新订单实时轮询，有新订单时右上角显示未读数字并播放提示音。
- **安全与配置**：后台目录名称支持自由修改（例如把 `public/admin` 改为自定义名称），增强安全性；密码采用加盐哈希存储。

## 环境要求

- **操作系统**：Linux（推荐 CentOS / Ubuntu / Debian）或 Windows
- **Web 服务器**：Nginx（推荐）或 Apache
- **PHP 版本**：PHP 7.4 / 8.0 / 8.1 / 8.2（推荐 PHP 8.0 或 8.1）
- **必需 PHP 扩展**：`pdo`, `pdo_mysql`, `curl`, `mbstring`, `openssl`, `gd`, `fileinfo`
- **数据库**：MySQL 5.7 或 8.0（字符集使用 `utf8mb4`）
- **缓存**：Redis 5.0+（可选；未安装时会自动使用本地文件缓存）

## 部署说明

### 1. 后端部署

1. **上传文件**：将 `backend` 目录中的全部文件上传至服务器站点目录。
2. **设置运行目录**：将 Web 站点的运行目录（Document Root）设置为 `/public`。
3. **设置目录权限**：确保 Web 运行用户（如 `www`）对以下目录具有读写权限：
   - `backend/runtime/`
   - `backend/config/`
   - `backend/public/uploads/`
4. **配置 Nginx 伪静态**：在 Nginx 配置中添加以下规则：
   ```nginx
   location / {
       try_files $uri $uri/ /index.php?$query_string;
   }

   # 顺丰回调直达
   location ~* ^/(sf_push|sf_route|sf_state)\.php$ {
       try_files $uri =404;
       fastcgi_pass unix:/tmp/php-cgi-80.sock;
       fastcgi_index index.php;
       fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
       include fastcgi_params;
   }

   # 禁止访问上传目录中的脚本文件
   location ~* ^/uploads/.*\.php$ {
       deny all;
   }

   # 禁止访问敏感文件
   location ~* \.(env|git|sql|bak|log|lock|ini)$ {
       deny all;
   }
   ```
5. **初始化安装**：
   - 在浏览器中访问站点域名：`http://您的域名/`。
   - 页面会自动跳转至安装向导，按提示填写数据库连接信息与管理员账号。
   - 安装完成后即可进入 PC 官网前台与管理后台（默认地址：`/admin/`）。

### 2. 小程序端编译与发布

1. 使用 **HBuilderX** 打开 `miniapp` 目录。
2. 打开 `miniapp/common/config.js`，将 `baseUrl` 修改为您的后端域名：
   ```javascript
   export default {
       baseUrl: 'https://您的接口域名.com',
       brandName: '启灵同城服务',
       version: '2.0.0'
   };
   ```
3. 打开 `manifest.json`，在【微信小程序配置】中填写您的微信小程序 AppID。
4. 在 HBuilderX 中点击【运行】➔【运行到小程序模拟器】➔【微信开发者工具】进行预览调试。
5. 调试无误后，通过【发行】➔【小程序-微信】打包上传至微信小程序管理后台提交审核。

## 使用与安全建议

1. **修改后台管理路径**：为避免默认 `/admin/` 路径被恶意扫描，可直接在服务器中将 `backend/public/admin/` 目录重命名为您自定义的名称（例如 `backend/public/my_manage/`），无需修改任何代码，之后通过 `http://您的域名/my_manage/` 访问即可。
2. **启用 HTTPS**：生产环境建议配置 SSL 证书并强制开启 HTTPS，保障用户数据与支付安全。
3. **关闭调试模式**：上线前请检查 `backend/config/app.php`，确认 `debug` 设置为 `false`。
