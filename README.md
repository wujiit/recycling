## 📖 项目简介

**启灵二手回收系统**是一套专为中国本土商业回收生态量身定制的全流程解决方案。系统采用**轻量原生 PHP 后端**架构，本仓库已完整内置 **PC 官网门户**与**现代化管理后台**，零臃肿复杂第三方包依赖，极速响应，易于二次开发与私有化部署。

系统内置行业领先的**多模态回收估价引擎**，支持从数码 3C 精品估价到大宗废品称重、二手车残值报废评估等 6 大行业业务场景的一键平滑切换。

### 🌟 核心特性
* **🚀 极简部署体验**：自带图形化一键安装向导，自动检测环境、自动建表建库，小白站长也能 5 分钟极速上线；
* **💻 PC 官网与后台开箱即用**：本仓库直接内置响应式 PC 官网回收门户与单页现代化管理后台，无需单独构建编译；
* **🔄 6 大主流行业模板一键切换**：
  1. **综合全品类大平台模式**：全品类网格化自由展示；
  2. **废品与再生资源模式**：废铜废铝废纸电瓶，按**公斤/吨**称重计价，支持预约上门过磅；
  3. **二手汽车与机动车报废模式**：家用燃油车、新能源电动车报废残值申领，按**万元/辆**评估；
  4. **数码 3C 精品回收模式**：手机、电脑、平板、相机，精准成色多维减扣算法；
  5. **奢侈品名表黄金回收模式**：名表名包、足金999首饰，按件/克鉴定现金结算；
  6. **二手大家电拆旧模式**：空调、冰箱、洗衣机拆旧，上门拆机搬运；
* **🚚 顺丰速运全流程物流闭环**：官方开放平台 API 深度对接，支持预约上门取件、生成顺丰电子面单、实时路由轨迹跟踪、运费清单与订单状态 Webhook 自动推送；
* **🔍 质检中心与二次核价**：开箱验机存证、成色多维复核、生成专业质检比对报告，支持补差确认或原路退回；
* **💰 多渠道财务结算放款**：支持**微信商家转账到零钱**、**支付宝单笔转账**与线下银行卡结算，财务审核一键放款；
* **🛡️ 同服 Redis 多租户安全隔离**：默认绑定 `DB 2` 与专属 `sys_recycle:*` 业务前缀，底层严禁 `flushdb`，采用 `SCAN + UNLINK` 精准扫描注销，保障同服务器其他站点缓存 100% 零误伤。

## 🚀 快速上手部署（宝塔面板 / qlnmp 环境）

### 1. 服务器环境需求
* **操作系统**：Linux (CentOS 7.9+ / Ubuntu 20.04+ / Debian 11+ / Alibaba Cloud Linux)
* **Web 服务器**：Nginx 1.18+ (推荐 1.22 ~ 1.24+)
* **PHP 版本**：PHP 7.4 / 8.0 / 8.1 / 8.2（推荐 PHP 8.0 或 8.1）
* **必需 PHP 扩展**：`pdo`、`pdo_mysql`、`curl`、`mbstring`、`openssl`、`gd`、`fileinfo`（宝塔后台一键安装）
* **数据库**：MySQL 5.7+ 或 8.0（字符集编码：`utf8mb4`）
* **缓存服务**：Redis 5.0+（可选，未安装时系统自动降级为本地文件高速缓存）

### 2. 部署极简 4 步走
1. **添加站点与上传源码**：在宝塔面板或 qlnmp 环境中创建站点，将本仓库 `backend` 目录文件上传至站点根目录；
2. **【重要】设置网站运行目录**：进入站点设置 ➔【网站目录】，将**运行目录**修改选择为 `/public`（即站点根目录下的 `backend/public` 目录），点击保存；
3. **配置目录读写权限**：确保以下目录具备 Web 用户（`www`）写入权限（`chmod -R 775`）：
   - `backend/runtime/`
   - `backend/config/`
   - `backend/public/uploads/`
4. **配置 Nginx 伪静态与安全规则**：进入站点设置 ➔【配置文件】或【伪静态】，填入以下核心规则：
   ```nginx
   # 1. 核心伪静态路由转发
   location / {
       try_files $uri $uri/ /index.php?$query_string;
   }

   # 2. 顺丰速运直达推送入口（免伪静态直接执行，请根据 PHP 版本调整 socket）
   location ~* ^/(sf_push|sf_route|sf_state)\.php$ {
       try_files $uri =404;
       fastcgi_pass unix:/tmp/php-cgi-80.sock;
       fastcgi_index index.php;
       fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
       include fastcgi_params;
   }

   # 3. 附件目录安全防线：严格禁止执行 PHP 脚本，防范木马上传
   location ~* ^/uploads/.*\.php$ {
       deny all;
   }

   # 4. 禁止直接访问敏感配置与锁定文件
   location ~* \.(env|git|sql|bak|log|lock)$ {
       deny all;
   }
   ```
5. **图形化一键安装**：
   - 在浏览器中直接打开您的站点网址：`http(s)://您的域名/`；
   - 系统将自动重定向进入可视化安装向导，按照界面提示完成环境自检、输入数据库账号密码；
   - 点击【开始一键初始化安装】，自动建表并装载数据，完成后即可直接访问 PC 官网前台与管理后台（`https://您的域名/admin/`）开展运营！
